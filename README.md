# CODSOFT Data Science Internship Tasks

This repository contains three independent beginner-friendly machine-learning projects:
- Task 1: Titanic Survival Prediction (classification)
- Task 3: Iris Flower Classification (classification)
- Task 4: Sales Prediction (regression)

## Setup
Use Python 3.10 or newer. From the repository root:

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Run each project
```bash
cd Task1_Titanic_Survival
python main.py --data train.csv
```
Download `train.csv` from the [Kaggle Titanic competition](https://www.kaggle.com/competitions/titanic/data) and place it in the Task 1 folder.

```bash
cd ../Task3_Iris_Flower_Classification
python main.py
```
Iris data is loaded directly from scikit-learn; no separate download is required.

```bash
cd ../Task4_Sales_Prediction
python main.py --data advertising.csv
```
Download a CSV with `TV`, `Radio`, `Newspaper`, and `Sales` columns from the [Kaggle Advertising Dataset](https://www.kaggle.com/datasets/ashydv/advertising-dataset) and place it in the Task 4 folder.

Each script prints evaluation results and creates an `outputs/` folder containing metrics and plots. The output folders are ignored by Git; run the projects locally first, then optionally commit selected result images/metrics if your internship submission expects evidence.

## Important
- Metrics are generated by running the scripts; they are not hard-coded.
- Do not upload Kaggle datasets unless their license and Kaggle's terms allow redistribution.
- Be prepared to explain your preprocessing, model choice and evaluation metrics in your demo.
